# Cursor plugin v0.1.5

- List thinking and non-thinking families separately (`<base>-thinking` vs `<base>`).
- Send Cursor sibling model IDs (`<base>-thinking-<effort>` or `<base>-<effort>`) instead of a bare base ID plus an `effort` parameter.
- Ignore `-fast` catalog rows. Default omitted `reasoning_effort` to `medium`.
- Treat `-max` as an effort tier, not Max mode. Max mode stays `max_mode` or `-1m`.
